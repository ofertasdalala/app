Termos de Uso

Esta ferramenta é uma automação pessoal utilizada para preparar, organizar e enviar vídeos promocionais para revisão na conta TikTok do próprio usuário.

1. Uso do serviço

O serviço permite ao usuário autorizado enviar vídeos selecionados por ele para sua própria conta TikTok, como rascunhos, para revisão e publicação manual.

2. Responsabilidade pelo conteúdo

O usuário é integralmente responsável pelos vídeos, textos, imagens, músicas, marcas, links e demais conteúdos enviados.

O usuário declara possuir os direitos necessários para utilizar e divulgar os materiais enviados.

3. Relação com o TikTok

Este serviço não é afiliado, patrocinado ou endossado pelo TikTok.

4. Publicação

O serviço não publica automaticamente conteúdo público no TikTok. Os vídeos enviados ficam disponíveis para revisão e publicação manual pelo usuário, conforme as permissões autorizadas.

5. Alterações

Estes termos podem ser atualizados periodicamente. O uso continuado do serviço implica aceitação da versão vigente.
