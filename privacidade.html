Política de Privacidade

Esta política explica como a automação trata informações quando você autoriza o acesso à sua conta TikTok.

1. Dados utilizados

Para permitir o envio de vídeos como rascunhos, podem ser processados:

  • Identificador da conta TikTok autorizada.
  • Token de acesso necessário para chamar a API do TikTok.
  • Vídeo selecionado pelo usuário.
  • Título, descrição e metadados relacionados ao vídeo.

2. Finalidade

Os dados são usados exclusivamente para permitir que o usuário envie seus próprios vídeos para sua conta TikTok como rascunhos.

3. Compartilhamento

Não vendemos, alugamos ou compartilhamos dados pessoais com terceiros para fins de publicidade.

Os dados podem ser processados pelo TikTok conforme as políticas e autorizações da própria plataforma.

4. Armazenamento

Os tokens e informações necessários ao funcionamento são armazenados apenas pelo tempo necessário para operar a automação.

5. Revogação do acesso

Você pode revogar o acesso do aplicativo à sua conta TikTok a qualquer momento nas configurações de segurança e permissões do TikTok.

Última atualização: 17 de outubro de 2026.
